Понятно и по-русски.

School Mail Bot готовит подробное содержание выбранных писем из Gmail и отправляет ежедневный отчёт в настроенную семейную группу Telegram.

Как работает бот

  1. Владелец почты разрешает чтение Gmail через Google OAuth.
  2. Бот выбирает письма только от настроенных отправителей за последние 24 часа.
  3. OpenAI составляет содержание на русском, выделяя просьбы, даты и суммы из письма.
  4. В 09:00 по Никосии начинается подготовка отчёта для семейной группы.
Доступ к Gmail — только для чтения. Разрешение Google технически охватывает весь ящик; ограничение выбранными отправителями реализовано в боте.

Для одной семьи

Это приложение для личного использования владельцем и его семьёй. Публичной регистрации и подключения посторонних почтовых ящиков нет.

Вложения перечисляются по имени; их содержимое не анализируется. Содержание важных писем следует сверять с оригиналом.

Данные и связь

Перед подключением ознакомьтесь с политикой конфиденциальности и условиями использования. По вопросам доступа и удаления данных обращайтесь к владельцу бота в семейной группе. Адрес поддержки также указан на экране согласия Google.
