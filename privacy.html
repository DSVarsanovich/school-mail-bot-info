School Mail Bot — личное приложение для подготовки русскоязычных отчётов о школьных письмах для владельца почтового ящика и его семьи.

Какие данные читает приложение

После согласия владельца приложение использует Gmail API с разрешением gmail.readonly. Google разрешает читать весь ящик; приложение выбирает письма по настроенным адресам отправителей и времени получения. Оно получает идентификаторы, отправителя, тему, время получения, текст выбранных писем и имена вложений. Содержимое файлов во вложениях не анализируется.

Приложение не отправляет и не удаляет письма, не изменяет их содержимое и не запрашивает пароль Gmail. Токены OAuth позволяют получать доступ без пароля.

Для чего нужны эти данные

Выбранный текст и метаданные нужны для подробного содержания на русском, выделения просьб, дат и сумм и доставки отчёта в заданную владельцем семейную группу Telegram. Приложение не использует письма для рекламы, продажи данных или формирования обучающих датасетов.

Передача сервисам

  • Google: предоставляет доступ к Gmail после согласия владельца.
  • OpenAI API: получает текст, отправителя, тему, время получения и названия вложений выбранного письма для подготовки содержания. Запросы отправляются с store=False; это не исключает отдельное хранение данных провайдером в целях безопасности согласно его условиям.
  • Amazon Web Services: выполняет обработку по расписанию и хранит настройки, токены и статусы отчётов.
  • Telegram: получает готовый отчёт, включая отправителя, тему и время получения. Сообщения видны участникам выбранной группы.

Передача данных служит только описанной пользователю функции. Использование и передача информации, полученной через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Хранение и защита

Исходный текст писем обрабатывается во время выполнения и не сохраняется приложением в базе статусов или логах. В базе могут храниться ID писем, готовые пересказы, части отчёта и состояние отправки. Для них установлен срок TTL семь дней; физическое удаление выполняется AWS асинхронно. Логи статусов и обезличенных типов ошибок хранятся семь дней. Очередь неудачных заданий хранится до 14 дней и не содержит исходные письма.

OAuth-токены и ключи хранятся в AWS SSM SecureString и в закрытой локальной конфигурации владельца до удаления или замены. Они не размещаются на этом сайте или в публичном репозитории. База и очередь используют шифрование AWS; обращения к внешним API выполняются по HTTPS.

Отчёты в Telegram и исходные письма в Gmail хранятся по правилам соответствующих сервисов. Их хранение не ограничивается семидневным TTL базы приложения.

Отзыв доступа и удаление

Владелец может отозвать разрешение в настройках подключений Google. Это остановит новый доступ к Gmail, но не удалит уже отправленные сообщения Telegram или ранее подготовленные отчёты автоматически.

Для остановки расписания и удаления конфигурации, токенов и сохранённых отчётов следует обратиться к владельцу бота в семейной группе. Сообщения Telegram удаляются отдельно с учётом прав участников и возможностей сервиса. Изменения правил обработки отражаются на этой странице.

Контакт

Приложение обслуживает владелец семейного бота. Связаться с ним можно в семейной группе Telegram либо по адресу поддержки на экране согласия Google.
